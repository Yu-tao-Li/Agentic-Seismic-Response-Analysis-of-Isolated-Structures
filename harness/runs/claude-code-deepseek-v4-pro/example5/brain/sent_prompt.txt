Background:
Nonlinear seismic response analysis of isolated structures requires consistent modeling of superstructure yielding, isolation-layer hysteresis, and state-variable updates. In this harness, correctness must be supported by cross-software verification.

Role:
Act as a structural engineer and coding agent. Produce executable, auditable analysis files for MATLAB, Python + OpenSeesPy, and ABAQUS, then compare the three results.

Aims:
Establish a four-story seismically isolated structure and calculate the top-story displacement and acceleration responses. The upper three stories follow an ideal elastic-plastic constitutive model. The isolation layer follows a bilinear constitutive model with kinematic hardening. Rayleigh damping is considered with damping ratio 0.05. The ground motion is read from `Northridge_01_NO_968.txt`, which contains one column of acceleration data. The time interval is 0.01 s. Normalize the peak ground acceleration to 0.40 g.

The values of `k2` to `k4`, `fy2` to `fy4`, `k1`, `fy1`, and `b` must come from the run-provided figure, parameter table, configuration file, or reference material. Do not invent missing engineering constants. If required values are absent, stop and record the missing inputs in `report.md`.

Instructions:
The success criterion is an auditable final agreement among MATLAB, OpenSeesPy, and ABAQUS.

Use the same physical model, units, input normalization, and output definitions in all software implementations.

1. MATLAB
   - Implement nonlinear MDOF time-history analysis.
   - Use Newmark-beta integration with an appropriate nonlinear iteration/update scheme.
   - Track superstructure yielding, isolation-layer kinematic hardening, restoring forces, and convergence status.

2. Python + OpenSeesPy
   - Build an equivalent nonlinear isolated shear-building model.
   - Use material and element definitions that reproduce the ideal elastic-plastic superstructure and bilinear kinematic-hardening isolation layer.
   - Apply the same normalized ground motion.

3. ABAQUS
   - Build an equivalent nonlinear model suitable for independent verification.
   - Post-process top-story displacement, top-story acceleration, isolation displacement, base shear, and hysteresis quantities.

Harness verification requirements:
For each software, write machine-readable response output containing:
- time vector
- top-story displacement
- top-story acceleration
- isolation-layer displacement
- base shear or isolation restoring force
- isolation hysteresis data
- yielding indicators where available
- convergence or failed-step count

Preserve the manuscript output names where applicable:
- `topStoDisIso2.txt`
- `topStoAccIso2.txt`

Then create `cross_validation_report.json` comparing MATLAB, OpenSeesPy, and ABAQUS by input consistency, peak response error, curve error, isolation displacement, base shear, hysteresis loop area, yielding sequence, and convergence behavior.

The agent may propose task-specific consistency thresholds for nonlinear and hysteretic response quantities. Record the thresholds and reasoning before final pass/fail is declared.

Necessary results:
- Three software-specific scripts or input files.
- Software-specific response outputs and logs.
- `cross_validation_report.json`.
- `report.md` describing modeling assumptions, nonlinear update rules, missing-input checks, encountered issues, corrections, adopted consistency criteria, and final agreement.
