# Single-Turn Model Speed and Price Benchmark

This directory contains the English benchmark package produced on June 27, 2026.

Contents:

- `experimental_plan.md`: benchmark objective, fixed prompt, procedure, fields, and formulas.
- `overall_report.md`: cross-model comparison and interpretation.
- `results/`: five-run raw and summarized results for each model.

Models:

1. Codex GPT-5.5
2. Claude Code with MiMo V2.5 Pro
3. Claude Code with MiMo V2.5 Pro UltraSpeed
4. Claude Code with DeepSeek V4 Pro

All formal samples are independent single-turn requests. Generated programs were not executed. Completion is defined as a successful one-turn response from the verified requested model; output-format and code-content deviations are disclosed separately.
